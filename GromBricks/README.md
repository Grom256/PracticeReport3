# GromBricks

Навчальний інтернет-магазин LEGO-мініфігурок і окремих деталей на Django та MySQL.

## Локальний запуск

Потрібні Python і MySQL Server 8.4. Структуру таблиць створюють Django migrations. MySQL-схему `grombrick` можна створити скриптом `database/create_schema.sql` або командою в MySQL:

```sql
CREATE DATABASE grombrick CHARACTER SET utf8mb4;
```

З кореня репозиторію скопіюйте приклад налаштувань і заповніть `.env` своїми параметрами MySQL. Не додавайте `.env` до Git:

```powershell
Copy-Item GromBricks\.env.example GromBricks\.env
```

Потім виконайте:

```powershell
cd GromBricks
..\.venv\Scripts\python.exe -m pip install -r requirements.txt
..\.venv\Scripts\python.exe manage.py migrate
..\.venv\Scripts\python.exe manage.py createsuperuser
..\.venv\Scripts\python.exe manage.py runserver
```

Django Admin відкривається за адресою `/admin/`. Назви змінних оточення наведені в `.env.example`; секретні значення зберігай лише у локальному `.env`.

## Структура даних

- `Category` — тематичні категорії товарів, наприклад серії LEGO.
- `Product` — мініфігурки й деталі з ціною, станом, залишком та ознакою рідкісного товару.
- `Order` — покупець, адреса, служба доставки, спосіб оплати та статус.
- `OrderItem` — склад замовлення з ціною товару на момент покупки.
- Реалізовані реєстрація, вхід/вихід і редагування базових даних профілю через стандартну автентифікацію Django.
- Кошик авторизованого користувача зберігається в сесії; доступні додавання, зміна кількості та видалення товарів із перевіркою залишку.
- Оформлення замовлення створює запис із позиціями та цінами на момент покупки, перевіряє наявність товарів і списує придбану кількість зі складу.
- Авторизований користувач може переглядати лише власні замовлення та їх склад.
- Каталог і сторінка товару працюють через `ListView` та `DetailView`. Авторизований користувач може створювати товари; редагувати й видаляти їх може власник, а також користувач із правом staff. Маршрути керування доступні з профілю.

Оплата в навчальній версії фіксується як переказ на картку або рахунок. Банківські реквізити картки покупця не збираються, а реальний платіжний сервіс не підключений.
